로또생성기 웹문서 만들기
버튼을 누르면 1~45 중 중복 없는 6개 번호를 뽑아 화면에 보여주는 웹페이지
기능 : 번호뽑기버튼, 공 6개가 화면에 표기, 오름차순 정렬, 초기화 버튼, 생성횟수표시
입력 : 버튼 클릭 
출력 : 번호찍힌 공모양, 생성횟수
제약 : html, css, javascript 만 사용 (단, css, html, javascript 폴더를 각각 만들어서 해당하는 폴더에 각각 파일을 생성). 외부 라이브러리 사용 금지, 파일 이름은 lottery.html
코드는 초보 개발자도 이해할 수 있을 정도로 간단하게, 함수와 변수에는 주석을 달아서 더욱 이해가 쉽게, 주석은 한국어로
확인기준:1~45 사이의 번호 6개가 항상 나오는지 확인, 초기화 시 초기 화면으로 돌아가는지 확인
